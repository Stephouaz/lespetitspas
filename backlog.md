# Product Backlog – Les Petits Pas

Statuts possibles : **À faire** · **En cours** · **Terminé**
Ce fichier est tenu à jour par l'IA (règle écrite dans AGENTS.md) et validé par le chef de projet.

- **US-xx** = User Story (une fonctionnalité visible par un utilisateur)
- **TECH-xx** = tâche technique (base de données, sécurité, tests…)
- **Priorité MoSCoW** : **Must** = indispensable au MVP ou exigé dans les livrables · **Should** = important, livré si possible · **Could** = amélioration facultative, si le temps le permet
- Données de test imposées : 3 enfants (Ana Maria, Sarah, Ilyès), 3 comptes (staff, parent 1 rattaché à Ana Maria et Sarah, parent 2 rattaché à Ilyès).
